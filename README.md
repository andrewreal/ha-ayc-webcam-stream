# AYC Webcam Add-on repository

Home Assistant add-on repository containing **AYC Webcam Stream** (`ayc_stream`),
which relays the Axe Yacht Club webcam to YouTube Live from a Raspberry Pi 4 (aarch64).

Install: Settings → Add-ons → Add-on Store → ⋮ → Repositories → add `https://github.com/andrewreal/ha-ayc-webcam-stream`,
install *AYC Webcam Stream*, set `stream_key`, start, enable Start on boot + Watchdog.
See [ayc_stream/DOCS.md](ayc_stream/DOCS.md).
